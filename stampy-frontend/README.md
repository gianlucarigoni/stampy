# stampy-frontend

Vue 3 + TypeScript + Vite + Vue Router + Bootstrap 5.3 (Sass only, no Bootstrap JS). Staff and customer web app (`BACKLOG.md` B7).

```bash
npm install
npm run dev     # needs the backend on :3000; /api is proxied, so the app stays same-origin
npm run build   # type-check + production build
```
