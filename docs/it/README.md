# Documentazione in italiano (sola lettura)

Queste sono **traduzioni di comodo** dei documenti in inglese di `docs/`, per leggerli
senza ambiguità quando l'inglese tecnico crea dubbi.

> ⚠️ **La fonte di verità è sempre l'inglese** (`docs/`). Qui non si modifica niente a mano
> come decisione: se una decisione o il codice cambiano, si aggiorna prima il file inglese
> e poi si rigenera/aggiorna la traduzione. In caso di differenza vince l'inglese; per
> `CODEBASE.md` vince comunque il codice.

Nomi di campi, endpoint, tabelle, comandi e stringhe API (anche quelle già in italiano nel
codice, come `"Riprova più tardi"`) restano letterali, come richiesto da `AGENTS.md`.
