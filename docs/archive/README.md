# Document archive

**Frozen** documents: they are not updated. They remain for history and to recover the
detail of decisions and verifications. When in doubt, the code wins.

> The archived files below are kept in their original language (Italian) and were
> deliberately **not** translated, since they are historical records. The living
> documents in `docs/` are in English.

There are three living documents, in `docs/`:

| File | Role |
|---|---|
| `CONTEXT.md` | context and decisions (static: changes only when a decision changes) |
| `CODEBASE.md` | code map, endpoints, data, tests (living) |
| `BACKLOG.md` | what is missing, including things designed and never built (living) |

| Archived file | What it contained |
|---|---|
| `stampy_contesto_progetto.md` | product and auth decisions (absorbed into `CONTEXT.md`) |

| `progress.md` | phase history, tests, lessons, sources consulted (absorbed into `BACKLOG.md` §8) |
| `Stampy_Handoff_Fase_4c.md` | Phase 4c handoff (email, session, `visit`/polling) |
